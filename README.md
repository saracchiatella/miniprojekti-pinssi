](# miniprojekti-PINSSI

Näin saat sovelluksen toimimaan:

Kopioi ympäristömuuttujatiedosto:
<code>cp .env.example .env</code>

Asenna riippuvuudet:
<code>uv sync</code>

Siirry virtuaaliympäristöön:
<code>source .venv/bin/activate</code>

Käynnistä sovellus:
<code>python3 src/index.py</code>
