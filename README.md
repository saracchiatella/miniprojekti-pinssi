# miniprojekti-PINSSI

Näin saat sovelluksen toimimaan:
<br>
<p>
Kopioi ympäristömuuttujatiedosto:
<br>
<code>cp .env.example .env</code>
</p>
<p>
Asenna riippuvuudet:
<br>
<code>uv sync</code>
</p>
<p>
Siirry virtuaaliympäristöön:
<br>
<code>source .venv/bin/activate</code>
</p>
<p>
Käynnistä sovellus:
<br>
<code>uv run src/db_helper.py</code>
<br>
<code>uv run python3 src/index.py</code>
</p>
